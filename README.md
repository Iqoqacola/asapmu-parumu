# Asapmu Parumu

Asapmu Parumu is an educational web application built with React and Vite to raise awareness about the dangers of smoking. The platform provides learning modules, health impact information, and interactive features to help users better understand smoking risks and prevention.

---

## 🛠️ Tech Stack

- Frontend: React (Vite)  
- Routing: React Router DOM  
- Styling: CSS  
- API Handling: Axios  

---

## ✨ Features

- Educational modules covering health, socio-economic impacts, and myths vs facts about smoking  
- User authentication system (login and registration)  
- Protected routes for secured educational content  
- Responsive design for multiple device sizes  

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Iqoqacola/asapmu-parumu.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```
